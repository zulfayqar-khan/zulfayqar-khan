# GitHub Profile Setup

This folder is meant for your special GitHub profile repository.

## What GitHub expects

To control the page at:

`https://github.com/zulfayqar-khan`

you need a **public repository** named exactly:

`zulfayqar-khan`

inside your GitHub account `zulfayqar-khan`.

## What to do

1. Create a new public repository named `zulfayqar-khan`.
2. Copy the contents of this folder into that repository.
3. Rename or replace the placeholder LinkedIn URL in `README.md`.
4. Add your CV PDF at:
   `assets/Zulfayqar_Khan_CV.pdf`
5. Commit and push.

## Files included

- `README.md`: the actual profile landing page content
- `assets/banner.svg`: the main hero banner
- `assets/quant-card.svg`: visual card for your finance project
- `assets/music-card.svg`: visual card for your music project
